# Universal Learning Architecture — Changelog

All notable changes to the Universal Learning Architecture (ULA) are recorded in this file.

Version format:

MAJOR.MINOR

Example:

- 1.0 = first stable architecture
- 1.1 = compatible improvement
- 2.0 = major structural redesign

---

## [1.0] — Initial Release

### Status

FROZEN BASELINE

### Added

- Universal Learning Architecture core specification.
- L0 — Map.
- L1 — Simple Explanation.
- L2 — Mechanism.
- L3 — Theory.
- L4 — Math / Formalism.
- R — Reference Layer.

### Added Core Principles

- Whole Before Parts.
- Mechanism Before Theory Before Math.
- Progressive Disclosure.
- Recursive Zoom.
- One Concept — One Home.
- Architecture Before Content.
- Stable Canonical Vocabulary.
- Reference Separation.
- Explicit confusion boundaries.
- Simple technical writing.

### Added Topic Adaptation

Support for:

- process / algorithm topics,
- statistical and ML models,
- system and software architecture,
- mathematical theory,
- quantitative finance,
- research papers and research projects,
- historical and causal subjects,
- skills and procedures.

### Added Workflow Roles

- Learning Architect.
- Learning Content Builder.
- Learning Auditor.

### Added Workflow

Project Brief
→ Architecture
→ Human Review
→ Frozen Architecture
→ Content Build
→ Audit
→ Revision or Freeze
→ Final Artifact

### Added Quality Controls

- architecture fidelity audit,
- layer separation audit,
- cognitive load audit,
- source fidelity audit,
- concept-home audit,
- vocabulary audit,
- reference separation audit,
- retrieval audit,
- oral explanation audit.

### Design Decision

The block is the primary unit of learning.

The page is not the primary unit.

### Design Decision

Reference material is separated from the main L0–L4 learning path.

### Design Decision

Complex blocks may recursively become new local maps.

### Design Decision

ULA is a reusable framework.

Individual learning projects should normally live outside the ULA framework directory.
